# Loan EMI Calculator

A web-based Loan EMI Calculator built using Python, Flask, HTML, CSS, and JavaScript.

The application calculates the Equated Monthly Installment (EMI) based on the loan amount, annual interest rate, and loan duration.

## Features

- Calculate monthly loan installments (EMI).
- Accept loan amount, annual interest rate, and loan duration.
- Validate user inputs.
- Handle zero-interest loans.
- Display the calculated EMI through a web interface.

## Technologies Used

- **Python** – Core calculation logic.
- **Flask** – Backend web framework.
- **HTML** – Page structure.
- **CSS** – User interface styling.
- **JavaScript** – User interaction and communication with the backend.
